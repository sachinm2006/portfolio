# Sachin Nagaraj Mevundi — Portfolio

A responsive, single-page portfolio highlighting Sachin’s work across software, electronics, and AI. Built with plain HTML, CSS, and JavaScript; no package installation or build step is needed.

## Run locally

Open `index.html` in a browser.

## Files

- `index.html` — page content, project links, and accessible navigation
- `styles.css` — responsive layout and iOS-inspired glass styling
- `script.js` — mobile navigation behavior
- `assets/` — monogram and high-resolution project preview images
